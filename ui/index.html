What should this panel run?

The module hands the 15 keys and the touch screen to Companion as two surfaces. You can change this later in Setup.

Companion on this panel KEY 6
Runs Companion here. You set up buttons, connections and pages in a browser at this panel's address, port 8000. Best when this rack is the only control surface, or the show runs from here.
Run Companion here
Companion Satellite KEY 8
Connects to a Companion already running on another computer. Buttons are set up on that computer. Best when the show already has a Companion machine.
Connect to Companion

Where is Companion running?

Tap the address and type it on the Stream Deck. This panel connects to Companion's Satellite port, 16622 unless it was changed there.
